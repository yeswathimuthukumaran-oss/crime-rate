# Investigation Reporting Tool

## About Project
A web-based application developed to manage and report crime-related information efficiently. The system allows users to register complaints and enables administrators to monitor and manage crime records.

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Features
- User Registration and Login
- Crime Complaint Registration
- Crime Record Management
- Admin Dashboard
- Search and Filter Reports
- Database Storage using MySQL

## Role
Developed frontend pages, database connectivity, and report management modules.

## Outcome
Improved organization of crime-related data and simplified report generation.
